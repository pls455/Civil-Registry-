# Minhaj AI

محرك ذكاء اصطناعي تعليمي محلي ومستقل، مبني بـ Python و C++ ويعمل بدون API أو خدمات سحابية.

## التشغيل

```bash
python3 app.py
```

ثم افتح `http://127.0.0.1:8080` من المتصفح على الهاتف أو الكمبيوتر.

- لا يحتاج API key.
- لا يحتاج اتصال إنترنت بعد تثبيت Python.
- قاعدة المعرفة محلية في `data/`.
- نواة C++ اختيارية وسريعة لعمليات النص.

## القدرات

المحادثة التعليمية، البحث داخل المحتوى، الشرح، التلخيص، توليد أسئلة، الاختبارات، تصحيح الإجابات، والحسابات الرياضية الأساسية.
