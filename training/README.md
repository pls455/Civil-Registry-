# تدريب نموذج منهاج محلي

## 1. إضافة البيانات
ضع كتب/دروس تملك حق استخدامها في `data/raw/` بصيغة `.txt` أو `.json`.

## 2. تجهيز البيانات
```bash
python training/prepare_dataset.py
```

ينتج `data/training.jsonl` بأمثلة تعليمية عربية.

## 3. تدريب baseline
ثبّت PyTorch على جهاز قوي نسبيًا ثم:
```bash
python training/train_torch.py
```

ينتج نموذجًا صغيرًا في `models/minhaj_char.pt`.

## 4. الجودة
هذا الـbaseline للتجربة والتعليم، وليس منافسًا لنماذج LLM الكبيرة. للوصول لجودة أفضل: استخدم نموذجًا عربيًا مرخصًا مسبق التدريب، ثم نفّذ fine-tuning/LoRA محليًا، وبعدها quantization إلى GGUF لتشغيله على Android.

لا تضع بيانات مقررات محمية بحقوق النشر في المستودع العام إلا إذا كان لديك ترخيص يسمح بذلك.
