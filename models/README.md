# Local model

ضع هنا ملف نموذج بصيغة GGUF باسم `model.gguf` إذا أردت التوليد اللغوي المحلي.

المحرك لا ينزّل نموذجًا ولا يتصل بأي خدمة. عند وجود `llama-cli` في PATH والنموذج محليًا، يستخدم `core/local_model.py` الاستدلال على الجهاز. بدونه يستمر النظام بمحركه المحلي الحتمي.

اختر نموذجًا صغيرًا متوافقًا مع إمكانيات الهاتف لتقليل استهلاك RAM والبطارية.
